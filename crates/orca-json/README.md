# orca-json

A scaffold: the crate holds only its name until task O1.8b of the translation's plan fills it.

It is to give JSON as the C++ front end's `nlohmann::json` does it: how numbers are read and kept (integers, unsigned, floating point), the ordering of object keys, and `dump` with its indent and its error handlers, so a result file is the same bytes.

Part of the Rust translation of sketch-orca (the workspace in the repository root; see the
repository's `README.md`, `BUILDING.md` and `CONTRIBUTING.md`). Licence: AGPL-3.0-only.

## Dependencies

None.
